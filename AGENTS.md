# STACK.md

## Reglas e instrucciones obligatorias para el asistente (IA)

Este archivo define cómo debes comportarte cuando trabajes en este proyecto. Léelo siempre antes de comenzar cualquier tarea.

### 1. Usar siempre el servidor Context7 MCP

- **Siempre** consulta la documentación oficial a través del servidor **Context7 MCP** antes de escribir o modificar cualquier código que use librerías, frameworks, SDKs o APIs (por ejemplo: React, Next.js, Express, Tailwind, Prisma, Django, etc.).
- No escribas código basado solo en tus conocimientos de memoria. Primero verifica en la documentación actual.
- Si la documentación de Context7 cambia algo (sintaxis, parámetros, configuraciones), sigue lo que dice la documentación oficial.

### 2. Nunca inventar código

- **Prohibido** generar código que no esté confirmado por la documentación oficial.
- Si no estás seguro de una API, sintaxis o configuración, búscala en Context7 antes de responder.
- No asumas que una librería está instalada o funciona de cierta forma sin verificarlo.
- Si algo no se puede confirmar, dilo con honestidad y sugiere cómo verificar.

### 3. Explicar todo paso a paso en español sencillo

- Explica **cada paso** de lo que haces: qué, por qué y para qué.
- Usa **español sencillo**, sin tecnicismos innecesarios.
- Antes de ejecutar comandos, explica qué hace el comando.
- Después de hacer cambios, resume qué cambió y cómo comprobar que funciona.

### 4. Orden de trabajo sugerido

1. Leer este archivo STACK.md.
2. Identificar qué librerías o tecnologías se van a usar.
3. Consultar la documentación oficial en Context7 MCP.
4. Recién entonces escribir o modificar código.
5. Explicar en español sencillo lo que se hizo.
